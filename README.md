## 📖 Project Overview

The Student Management System is a simple application that helps manage student records such as personal details, marks, attendance, and reports.

---

## 🎯 Objectives

- Manage student information efficiently.
- Store academic records.
- Improve data organization.
- Generate student reports.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| Add Student | Add new student records |
| Update Student | Edit existing student details |
| Delete Student | Remove student records |
| Search Student | Find a student by ID or name |
